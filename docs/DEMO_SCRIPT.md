# Demo script (about 5 minutes)

**Before:** keys in `backend\.env`, `python backend\run.py`, Settings → Test connection on AMD and Cloudflare images (all should read "Verified working"). Set the price variables so cost is not "unknown". Run `python scripts\amd_evidence.py`. Have a fresh campaign *and* one already generated as a backup.

1. **Problem (20 s).** One brand message sent to everyone wastes budget; personalised work is slow and costly.
2. **Brief (45 s).** Create Campaign: a real product, two very different audiences, two verified facts, a word to avoid, no discount.
3. **Generate (60 s).** Show progress. Point out the shared creative platform, then two clearly different headlines, copy and CTAs.
4. **Images (45 s).** Generate hero images; open Ad Preview.
5. **Experience (45 s).** Play a story, choose different branches; the CTA click appears in Campaign Stats.
6. **Human + AI (45 s).** Brand checks: show a flagged unsupported claim, edit the text, watch the check update; note the disclaimer.
7. **Cost & who pays (30 s).** Usage card: tokens, latency, cost per experience (real figure). Buyers: agencies and in-house brand teams who today pay per variant.
8. **AMD (30 s).** Settings: AMD verified, model, host, latency; show `evidence\amd_evidence.json` and the AMD console.

Do not claim: PwC/Imment integration, Evolus workflows, conversion uplift, or anything not shown on screen.
