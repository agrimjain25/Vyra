# Claims and evidence rules

A factual claim about the product is allowed only if it is listed under "verified facts" in the campaign brief.
If it is not in the verified facts, it is an **unsupported claim**.

## Claims that always need a verified fact
- Sustainability: sustainable, eco-friendly, carbon neutral, net zero, biodegradable, compostable, planet-friendly.
- Materials and ingredients: recycled, upcycled, organic, vegan, non-toxic, BPA-free, cruelty-free, fair trade, hypoallergenic.
- Health or scientific: clinically proven, scientifically tested, dermatologist approved, doctor recommended, cures, heals, treats, prevents.
- Proof or endorsement: proven, guaranteed, certified, lab-tested, award-winning, patented.
- Performance: waterproof, water-resistant, windproof, shockproof, indestructible, unbreakable, lifetime warranty.
- Durability: durable, long-lasting, tested.

## Superlatives and comparisons (warning, needs proof)
best, fastest, lightest, strongest, ultimate, unbeatable, unmatched, number one, leading, revolutionary,
breakthrough, perfect, flawless, miracle, game-changing, "world's first / best / most".

## Numbers
Every number in the copy (percentages, weights, distances, prices, years) must also appear in the brief or the verified facts.

## How to report
For each problem, quote the exact text from the copy as evidence, say which rule it breaks, name this document as the
source, and suggest a safe rewrite. If nothing is wrong, report no findings. Never invent problems.
